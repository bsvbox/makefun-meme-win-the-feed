A meme about make.fun for people who build AI agents: my agent at 3 AM, entering make.fun bounties and getting paid in USDC. Posted on X from @bsvbox tagging @_myronera. The image (meme.png) was drawn from scratch with PIL in the build session, no downloaded pictures, no copied templates.

## Run it

```sh
node main.ts
```

It reads POST.json from this repository, validates the X post URL, and copies it to the output directory (MAKEFUN_OUTPUT_DIR, default ./output).
